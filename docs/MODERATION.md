# 신고가 들어왔을 때

> 신고 접수 푸시를 받은 뒤 무엇을 확인하고 무엇을 할 수 있는지.
> 마지막 갱신: **2026-09-28**

---

## 0. 먼저 알아야 할 것 — 이 앱은 열린 광장이 아니다

밴드는 **초대코드로만** 들어온다. 모르는 사람이 남의 밴드 글을 볼 수 없고, 검색으로
찾아지지도 않는다. 그래서 신고는 대부분 **서로 아는 사람 사이에서** 나온다.

이 점이 조치 방법을 정한다. **낯선 사람의 악의적 도배가 아니라 밴드 안의 다툼**이라면,
계정 정지 같은 큰 수단보다 **밴드장이 정리하는 것**이 맞고 실제로 그게 가능하다.

---

## 1. 알림을 받으면 — 내용 확인

푸시에 신고 번호가 찍힌다. 그 번호로 본다. 명령은 모두 `tools/moderate.py` 하나로 한다(배포 키
`~/.ssh/bandule_deploy` 필요 — 서버에 SSH 로 들어가 DB·Redis 에 직접 쓴다).

```bash
python tools/moderate.py reports        # 처리 안 된 신고 목록 (target_type, target_id)
python tools/moderate.py post 123       # target_type 이 POST 면 그 글 내용과 첨부
```

`MEDIA` 신고는 첨부 번호다 — 어느 글에 달렸는지는 `hide-media` 가 먼저 보여 준다(확인 뒤 취소할 수 있다).

> **여기서 남의 글을 읽는다.** 신고 처리에 필요한 최소한만 보고, 다른 목적으로 쓰지 않는다.

---

## 2. 할 수 있는 일

| | 누가 · 어떻게 |
|---|---|
| 상대를 **차단** (서로 글이 안 보임) | 이용자가 앱에서. **즉시 효력, 가장 빠른 해결** |
| 글 삭제 · 멤버 내보내기 | **밴드장**이 앱에서 |
| 남의 밴드 글 숨김 | 운영자 — `moderate.py hide-post 글번호` (첨부가 문제면 `hide-media 첨부번호`, 글째 숨긴다) |
| **계정 이용 정지** | 운영자 — `moderate.py suspend 사용자번호 --days N --reason "..."` (약관 제14조 제5~8항) |
| 정지 해제 | 운영자 — `moderate.py unsuspend 사용자번호` |
| 조치 없이 신고만 닫기 | 운영자 — `moderate.py resolve 신고번호` |

모든 명령은 **바꿀 대상을 먼저 보여 주고 `yes` 를 입력해야 실행**한다.

### (가) 밴드장에게 연락한다 — 기본값

대부분의 신고는 이쪽이 맞다. 밴드장은 글을 지우고 멤버를 내보낼 수 있고, **밴드 안의
사정을 우리보다 잘 안다.** 신고자에게도 "차단하면 즉시 안 보인다" 를 안내한다.

### (나) 운영자가 직접 — 불법 촬영물·명백한 범죄, 밴드장이 가해자인 경우 등

**글 숨김** — `hide-post` 는 앱의 글 삭제와 같은 표시(`deleted_at`)를 찍고, 첨부의 보관기한을 지금으로
당겨 **매일 04:15 만료 배치가 저장소(R2)에서 지운다.** 그 전에도 앱에서는 안 보인다(주소를 새로 주지 않는다).
그 글에 걸린 신고는 처리 완료로 바뀐다. 첨부 하나만 지우는 기능은 없다.

**계정 정지** — 정지하면:

- 로그인·토큰 갱신이 막히고 앱에 "이용이 정지된 계정이에요 (M월 D일까지). 이의가 있으면 notice@bandule.com"
  이 뜬다. 쓰던 토큰도 **즉시** 막힌다(Redis 차단 표시).
- 그 사람 기기로 가던 푸시가 끊긴다(기기 토큰 삭제). 밴드 멤버십·글은 그대로 — 글까지 내리려면 `--hide-posts`.
- 기간이 지나면 **저절로 풀린다.** 영구 정지는 `--forever`.
- `--reason` 은 운영 기록이다(본인에게 그대로 보이지 않는다). 신고 번호를 같이 적는다.

기간 기준(약관 제14조 제5항 — 제9조 위반의 정도에 따라):

| 경우 | 기간 |
|---|---|
| 불법 촬영물·음란물 등 법령을 명백히 위반, 같은 위반 되풀이 | `--forever --hide-posts` |
| 비방·모욕, 권리 침해 게시물 (첫 위반) | 밴드장 조치로 충분하면 정지 안 함. 밴드장이 가해자면 `--days 7` |
| 같은 사람이 여러 밴드에서 반복 신고 | `--days 30` |

**정지한 뒤 반드시 본인에게 메일을 보낸다**(약관 제14조 제7항) — 스크립트가 마지막에 가입 이메일을 보여 준다.

```
제목: [밴듈] 서비스 이용 정지 안내

안녕하세요, 밴듈입니다.
회원님의 계정이 이용약관 제9조 제N호(…) 위반으로 YYYY-MM-DD 까지 이용 정지되었습니다.
(정지 사유: …)
이의가 있으시면 이 메일을 받은 날부터 7일 이내에 notice@bandule.com 으로 회신해 주세요.
검토 후 결과를 알려 드리며, 이의가 타당하면 즉시 정지를 해제합니다.
```

이의를 받으면 7일 안에 답하고, 타당하면 `unsuspend` 한다.

> **`users.deleted_at` 을 손으로 채우지 말 것.** 탈퇴로 취급돼 90일 뒤 개인정보가 파기된다.
> 정지는 `suspended_until` 이다 — 스크립트만 쓴다.

---

## 3. 처리 후

`hide-post`·`suspend` 는 관련 신고를 알아서 처리 완료로 바꾼다. 조치하지 않기로 한 신고는
`resolve` 로 닫는다. **안 닫으면 다음에 볼 때 또 목록에 나온다.**

---

## 4. 언제 더 만들까

지금은 **신고가 실제로 들어오지도 않는 단계**다. 운영자 화면·API 는 아직 이르고, `tools/moderate.py` 로 충분하다.

만들 때가 되는 신호:

- 신고가 **주 단위로** 들어온다 → 신고 목록 화면
- 운영자가 둘 이상이 된다 → SSH 키를 나눠 주는 대신 운영자 역할·API

계정 정지는 2026-09-28 에 만들었다(LAUNCH_REVIEW P7) — 13~15세를 대상에 넣은 UGC 앱이라 스토어 출시 전에
운영자가 쓸 수단이 있어야 했다. 정지 기간·고지·이의 절차는 약관 제14조 제5~8항.
