# 개인정보처리방침에 넣을 사실

> 값은 전부 코드에서 확인한 것이고, 근거 파일을 함께 적었다.
> 마지막 확인: **2026-09-06**

---

## 1. 수집하는 개인정보

### 가입할 때

| 항목 | 언제 | 필수 | 근거 |
|---|---|---|---|
| 이메일 | 이메일 가입 | 필수 | `users.email` |
| 비밀번호 | 이메일 가입 | 필수 | `users.password_hash` — **원문은 저장하지 않고 해시만 보관** |
| 이름(닉네임) | 모든 가입 | 필수 | `users.name` |
| 카카오 회원번호 | 카카오 가입 | 필수 | `users.social_id` |
| 카카오 이메일 | 카카오 가입 | **선택** | 이용자가 동의하지 않으면 안 받고, **없어도 가입된다** (`KakaoApiClient:55`) |
| 카카오 닉네임 | 카카오 가입 | 선택 | 미동의 시 없음 (`KakaoUserInfo`) |

> 카카오에서 받는 것은 **회원번호·이메일·닉네임 셋뿐**이다. 프로필 사진, 성별, 연령대,
> 생일, 전화번호는 받지 않는다.

### 서비스를 쓰면서 쌓이는 것

| 항목 | 내용 |
|---|---|
| 밴드 정보 | 밴드 이름, 멤버 구성, 역할(밴드장/멤버) |
| 합주 일정 | 날짜·시간, 장소, 참석 여부, 메모 |
| 합주실 정보 | 이름, 주소, 좌표, 시간당 요금 |
| 정산 기록 | 금액, 분담 내역, 납부 여부 |
| 게시글·댓글 | 본문 |
| 사진·영상 | 이용자가 게시글에 올린 파일 |
| 기기 푸시 토큰 | 알림을 보내기 위해. 기기 종류(Android/iOS) 포함 (`device_tokens`) |
| 신고 내역 | 신고 대상, 사유, 신고한 사람 (`reports`) |
| 차단 목록 | 서로 글이 보이지 않게 한 상대 (`user_blocks`) |

### 자동으로 처리되는 것

**접속 IP** — 짧은 시간에 같은 요청이 몰리는 것을 막는 데만 쓴다(가입·로그인, 초대코드
사용, 파일 업로드 등). **Redis 에 분 단위로만 두고 DB 에는 저장하지 않는다.**
(`common/ratelimit/`, `app.ratelimit.*`)

## 2. 보관 기간

| 대상 | 기간 | 근거 |
|---|---|---|
| **탈퇴 회원 정보** | **탈퇴 후 90일** 보관 후 파기 | `app.withdrawal.retention-days` |
| 무료 밴드의 사진·영상 | **올린 지 30일**이 지나면 삭제 | `app.plan` — 유료 밴드는 무제한 |
| 유료가 끝난 밴드의 사진·영상 | 무료로 바뀐 뒤 **30일** | 구독 주기와 무관한 유예 (`PlanProperties`) |
| 알림 발송 이력 | **30일** | `app.notification.dispatch-retention-days` |
| 로그인 유지 정보 | 최대 **14일** (쓰는 동안 연장) | `app.jwt.refresh-token-ttl` |
| 그 밖의 기록 | 회원이 탈퇴하거나 밴드가 삭제될 때까지 | |

> **밴드를 삭제하면** 그 밴드의 게시글·첨부·일정·정산·합주실·멤버 기록이 전부 지워지고,
> 올렸던 사진·영상도 저장소에서 삭제된다.

> **탈퇴하면** 이메일·이름·카카오 식별자가 익명 처리되고, 90일 뒤 완전히 파기된다.
> 다른 멤버가 함께 만든 밴드 기록(일정·정산)은 남는다 — 남의 기록이기도 해서다.

## 3. 제3자 · 처리 위탁

| 받는 곳 | 무엇을 | 왜 |
|---|---|---|
| **카카오** (Kakao Corp.) | 카카오 회원번호·이메일·닉네임 | 카카오 로그인 |
| **카카오** | 검색어, 주소 | 합주실 지도·장소 검색·주소→좌표 변환 |
| **Cloudflare** | 올린 사진·영상, 접속 요청 | 파일 보관(R2), 트래픽 중계 |
| **Google** (Firebase) | 기기 푸시 토큰, 알림 내용 | 푸시 알림 발송 |

**광고·마케팅 목적으로 개인정보를 제3자에게 제공하거나 판매하지 않는다.**

### 국외 이전 — 반드시 알려야 한다

| 받는 곳 | 나라 | 항목 |
|---|---|---|
| Cloudflare, Inc. | 미국 (전 세계 분산) | 사진·영상 |
| Google LLC | 미국 | 기기 푸시 토큰, 알림 제목·내용 |

> 카카오는 국내 사업자라 국외 이전에 해당하지 않는다.

## 4. 이용자의 권리

| 권리 | 지금 되는 방법 |
|---|---|
| 열람·수정 | 앱 안에서 (설정 > 계정) |
| **회원 탈퇴** | **앱 안에서 (설정 > 계정 > 회원 탈퇴)** — 별도 요청 없이 즉시 |
| 다른 이용자 차단 | 게시글 길게 눌러 차단 (설정 > 차단한 사용자에서 해제) |
| 신고 | 게시글 길게 눌러 신고 |
| 알림 끄기 | 설정 > 알림 설정, 또는 휴대폰 알림 권한 해제 |

## 5. 안전 조치 (실제로 하고 있는 것)

- 통신 구간 전체 **HTTPS** 암호화
- 비밀번호는 **원문을 저장하지 않고 해시로만** 보관
- 사진·영상은 **10분짜리 임시 주소**로만 내려받게 하고, 저장소를 직접 열지 못한다
- 모든 요청에서 **요청자가 그 밴드 소속인지 검사**한다 (다른 밴드 데이터 접근 차단)
- 데이터베이스는 **매일 자동 백업**하고 암호화된 저장소에 7일치 보관

## 7. 아직 안 하는 것 — 쓰면 안 되는 문구

생성기가 기본으로 넣어 주는 항목 중 **우리 앱에 해당하지 않는 것들**이다. 지우지 않으면
사실과 다른 방침이 된다.

- ❌ **결제·환불** — 유료 요금제 전환은 지금 쿠폰으로만 되고, **실제 결제가 없다.**
  결제를 붙일 때 함께 쓴다
- ✅ **만 14세 미만** — 가입 시 "만 14세 이상이에요" 를 필수로 확인한다(이메일·카카오 둘 다).
  법정대리인 동의 절차를 만드는 대신 **아동의 개인정보를 받지 않는 쪽**을 택했다.
  방침에도 그렇게 쓰면 된다
- ❌ **쿠키** — 앱이라 쓰지 않는다
- ❌ **광고 식별자·행동정보** — 광고 SDK 가 없다
- ❌ **CCTV·영상정보처리기기** — 없다
- ⚠️ **신고 처리** — 접수되면 운영자에게 푸시가 간다(2026-09-06). 다만 **계정 정지 같은
  조치 수단이 아직 없다.** 기한을 약속하지 않는 문구로 쓴다 (terms-draft.md 참조)
