# 약관·개인정보처리방침 초안

> **이건 법률 문서가 아니라 "사실 정리"다.**
>
> 생성기나 표준 양식에 넣을 값을 코드에서 뽑아 정리한 것이다. 문구의 법적 효력은
> 검토받지 않았다. 그대로 게시하지 말고, 생성기에 넣거나 사람이 다듬은 뒤 올린다.

## 왜 이렇게 하나

남의 약관을 베끼면 **우리 앱이 실제로 하지 않는 일**이 들어간다. 개인정보처리방침은
사실과 다르면 그 자체가 위반이라, 어렵더라도 "우리가 진짜 뭘 하는지"에서 출발해야 한다.

여기 적힌 수집 항목·보관 기간은 전부 **코드에서 확인한 값**이다. 근거 파일을 함께 적어
뒀으니, 나중에 동작이 바뀌면 이 문서도 같이 고친다.

## 채워야 하는 것

코드에서 못 뽑는 값이다. `⟨⟩` 로 표시해 뒀다.

- 서비스 운영자 이름(개인 또는 사업자명)
- 문의받을 이메일 주소
- 개인정보 보호책임자 이름·연락처
- 사업자등록번호 (사업자로 운영한다면)
- 게시 예정 주소 — `bandule.com/privacy`, `bandule.com/terms`
