# Play Console "앱 콘텐츠" 답안

> 스토어 제출 전에 채워야 하는 **선언 항목**을 콘솔 화면 순서대로 정리한다.
> 값은 전부 코드·설정에서 확인한 것이고 근거를 함께 적었다. 콘솔에 그대로 옮겨 넣으면 된다.
> 라벨은 콘솔 개편에 따라 조금씩 바뀐다 — 뜻이 같은 항목을 고른다.
>
> 사실 근거의 원본은 [privacy-facts.md](privacy-facts.md). 둘이 어긋나면 코드를 다시 확인한다.
> 마지막 확인: **2026-09-09**

---

## 0. 먼저 고쳐야 하는 것 세 가지

**이걸 먼저 처리하지 않으면 아래 답안 중 일부가 거짓이 되거나 제출이 막힌다.**

### 0-1. `privacy-facts.md` 가 "실제 결제 없음" 으로 남아 있다 — 사실과 다르다

`privacy-facts.md` §7 에 **"❌ 결제·환불 — 유료 요금제 전환은 지금 쿠폰으로만 되고, 실제 결제가
없다"** 고 적혀 있는데, Phase 12(2026-09-09)에서 Google Play 인앱결제가 들어갔고 실결제까지
확인했다. 그대로 두면:

- 개인정보처리방침에 **결제 관련 조항이 빠진다** (구매 이력 보관, Google 과의 관계)
- 아래 **데이터 안전 설문의 "금융 정보 › 구매 내역"** 을 빠뜨리게 된다

→ `privacy-facts.md` 와 `privacy-policy-ko.md` 에 결제 항목을 넣고 사이트에 다시 올린다.
서버가 저장하는 것은 **구매 토큰·주문 ID·구독 만료일**이고(`band_plans.purchase_token`,
`store`, `expires_at`), **카드번호 같은 결제수단 정보는 받지도 저장하지도 않는다**(Google 이 처리).

### 0-2. 위치 권한을 선언해 놓고 쓰지 않는다

`client/android/app/src/main/AndroidManifest.xml` 이 `ACCESS_FINE_LOCATION`·
`ACCESS_COARSE_LOCATION` 을 선언한다(주석은 "카카오맵 SDK 요건"). 그런데 **앱은 기기 위치를 한 번도
읽지 않는다** — `geolocator`·`permission_handler` 같은 의존성이 `pubspec.yaml` 에 없고,
지도 화면의 `hasLocation` 은 **합주실의 좌표**이지 이용자 위치가 아니다.

쓰지 않는 위치 권한은 심사에서 "왜 필요한가" 를 부르고, 데이터 안전 답안과도 어긋나 보인다.
**두 줄을 지우고 릴리스 빌드가 정상인지 확인하는 쪽을 권한다.** 나중에 "내 위치" 기능을 넣을 때
같이 되살리면 된다.

### 0-3. 계정 삭제 **웹 URL** 이 없다

Play 는 앱에서 계정을 만들 수 있으면 **앱 안의 삭제 경로**와 **웹에서 접근 가능한 삭제 요청
URL** 을 **둘 다** 요구한다. 앱 안 경로는 있다(설정 › 계정 › 회원 탈퇴). 웹 페이지가 없다 —
`site/` 에 `index`·`privacy`·`terms` 뿐이다.

→ `site/delete-account/index.html` 을 만들어 `bandule.com/delete-account` 로 띄운다.
내용은 (1) 앱 안에서 삭제하는 방법, (2) 앱을 못 쓰는 경우의 문의 이메일, (3) **무엇이 지워지고
무엇이 남는지**(탈퇴 시 이메일·이름·카카오 식별자 익명화 후 90일 뒤 파기, 함께 만든 밴드 기록은
남음) 세 가지면 된다.

## 2. 앱 액세스 권한

| 항목 | 답 |
|---|---|
| 모든 기능을 제한 없이 사용할 수 있나요? | **아니요 — 로그인이 필요합니다** |

심사자용 계정을 반드시 남긴다. **카카오 로그인은 심사자가 쓸 수 없으므로 이메일 가입 계정을
준다.** 계정만 주면 대부분 화면이 비어 보이니 아래를 함께 적는다.

- 이메일 / 비밀번호 (심사 전용으로 하나 새로 만든다)
- **밴드에 이미 소속된 계정으로 준비한다.** 밴드가 없으면 일정·정산·게시판이 전부 빈 화면이다.
- 안내문에 넣을 것: "로그인 후 하단 탭에서 일정·정산·게시판을 볼 수 있습니다.
  인앱결제(연 ₩19,000 구독)는 밴드장 계정의 [설정 › 요금제]에서 확인할 수 있습니다."

## 4. 콘텐츠 등급 (IARC 설문)

| 질문 | 답 |
|---|---|
| 폭력 / 성적 콘텐츠 / 욕설 / 약물 / 도박 | **전부 없음** |
| 사용자 간 상호작용이 있나요? | **예** — 게시판 글·댓글, 사진·영상 공유 |
| 사용자가 위치를 공유하나요? | **아니요** — 합주실 주소는 장소 정보이지 이용자 위치가 아니다 |
| 개인정보를 다른 사용자와 공유하나요? | **아니요** (밴드 안에서 이름이 보이는 것은 해당 없음) |
| 디지털 구매가 있나요? | **예** — 밴드 PREMIUM 구독 (연 ₩19,000) |

> UGC 가 있으면 심사에서 **신고·차단·운영 대응**을 확인한다. 셋 다 있다 —
> 게시글 신고(`reports`), 사용자 차단(`user_blocks`), 신고 접수 시 운영자 푸시.
> 운영 기준은 [MODERATION.md](../MODERATION.md). 다만 **계정 정지 같은 조치 수단은 아직 없으니**
> 처리 기한을 약속하는 문구는 쓰지 않는다.

## 5. 타겟층 및 콘텐츠 — **결정이 필요하다**

가입할 때 **만 14세 이상**을 필수로 확인한다(이메일·카카오 둘 다). 그래서 콘솔의 연령대 선택이
그대로 갈리지 않는다.

| 고르는 값 | 뜻 | 대가 |
|---|---|---|
| **18세 이상만** (권장) | 성인 대상 앱으로 신고 | 가장 단순하다. Families 정책·아동 보호 요건이 안 붙는다. 대신 **실제로 중·고등학생 밴드가 쓰면 신고 내용과 어긋난다** |
| 13~15세 포함 | 청소년도 대상 | **Families 정책**이 적용된다 — 콘텐츠 심사가 강해지고, 광고 ID·데이터 취급 제약이 붙는다. UGC 앱이라 부담이 크다 |

**권장: 18세 이상만.** 다만 이걸 고르면 가입 게이트도 "만 18세 이상"으로 올리는 게 맞다 —
지금은 만 14세다. **둘을 맞추지 않으면 신고와 실제가 어긋난다.** 어느 쪽으로 갈지 정하고,
정한 대로 가입 화면 문구까지 바꾼다.

| 그 밖의 질문 | 답 |
|---|---|
| 아동의 관심을 끌 만한 요소가 있나요? | **아니요** |
| 스토어 등록정보가 아동을 대상으로 하나요? | **아니요** |

## 6. 데이터 보안 (데이터 안전 양식)

### 공통 답

| 질문 | 답 | 근거 |
|---|---|---|
| 전송 중 데이터를 암호화하나요? | **예** | 전 구간 HTTPS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 앱 안 회원 탈퇴 + 0-3 의 웹 URL |
| 제3자와 데이터를 공유하나요? | **아니요** | 처리 위탁(카카오·Cloudflare·Google)은 Play 기준 "공유"가 아니다. 광고·마케팅 목적 제공·판매 없음 |

### 수집하는 데이터

전부 **수집함 / 공유 안 함 / 앱 기능 목적**이다. 계정 삭제 시 함께 삭제된다.

| 분류 › 유형 | 필수 | 근거 |
|---|---|---|
| 개인 정보 › 이름 | 필수 | `users.name` |
| 개인 정보 › 이메일 주소 | 이메일 가입 필수 / 카카오는 **선택** | `users.email`. 카카오는 미동의 시 안 받고도 가입된다 |
| 개인 정보 › 사용자 ID | 필수 | 카카오 회원번호 `users.social_id` |
| 금융 정보 › 구매 내역 | 필수 | **구독 구매 토큰·주문 ID·만료일** (`band_plans`). 결제수단 정보는 받지 않는다 — Google 이 처리 |
| 사진 및 동영상 › 사진 | 선택 | 게시글 첨부 |
| 사진 및 동영상 › 동영상 | 선택 | 게시글 첨부 |
| 메시지 › 기타 인앱 메시지 | 선택 | 게시글·댓글 본문 |
| 앱 활동 › 기타 사용자 생성 콘텐츠 | 필수 | 밴드·일정·참석·정산·합주실 기록 |
| 기기 또는 기타 ID | 선택 | FCM 푸시 토큰 (`device_tokens`). 알림을 켤 때만 |

### 수집하지 **않는** 것 — 물어보면 이렇게 답한다

| 유형 | 왜 아닌가 |
|---|---|
| **위치** | 기기 위치를 읽지 않는다. 합주실 좌표는 **이용자가 입력한 장소**의 좌표다. (0-2 의 권한도 지운다) |
| **IP 주소** | 레이트리밋 용도로 **Redis 에 분 단위로만 두고 DB 에 저장하지 않는다.** Play 의 "일시적으로만 처리되는 데이터" 예외에 해당해 수집으로 신고하지 않는다 (`common/ratelimit/`) |
| 앱 정보 및 성능(크래시 로그) | 크래시 리포팅 SDK 가 없다 |
| 연락처·통화기록·SMS·캘린더·건강 | 접근하지 않는다 |
| 결제수단 정보 | Google Play 결제라 앱·서버가 카드정보를 보지 않는다 |
