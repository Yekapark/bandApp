# 생성기 결과물을 그대로 쓰지 않은 이유

> Lokuma 생성기가 만든 영문 방침(2026-09-06)을 코드와 대조한 기록.
> 다음에 다른 생성기를 쓸 때도 같은 함정에 빠지지 않도록 남긴다.

생성기는 **"SaaS 회사라면 보통 이렇다"** 를 채워 준다. 우리가 실제로 뭘 하는지는 모른다.
개인정보처리방침은 **사실과 다르면 그 자체가 위반**이라, 안 쓰는 것보다 틀리게 쓰는 게 나쁘다.

---

## 1. 사실이 아닌 내용 (반드시 지워야 한다)

| 생성기가 쓴 것 | 실제 |
|---|---|
| API tokens and integration credentials | **없다.** 그런 기능이 없다 |
| Usage telemetry (features used, session duration, error reports) | **수집하지 않는다.** 분석 SDK 가 하나도 없다 |
| Subscription tier and **billing history** | **결제가 없다.** 유료 전환은 쿠폰으로만 된다 |
| Profile information (**avatar**, organization) | 아바타·조직 개념이 없다 |
| Auth0 / Supabase Auth / **Clerk** | 안 쓴다. 자체 인증 + 카카오 |
| Payment processors (**Stripe**) | 안 쓴다 |
| **AWS / Vercel / Supabase** | 안 쓴다. Vultr + Cloudflare R2 |
| Error monitoring (**Sentry / Datadog**) | 안 쓴다 |
| Customer support tools (**Intercom / Zendesk**) | 안 쓴다 |
| **"We are committed to SOC 2 controls"** | **사실이 아니다.** 감사받은 적이 없다. 이런 문장은 허위 표시가 될 수 있어 가장 위험하다 |
| Standard Contractual Clauses (SCCs), GDPR DPA | EU 이용자를 대상으로 하지 않는다. 지금은 과하다 |

> **가장 심각한 것은 SOC 2 문장이다.** 받지도 않은 인증을 언급하는 셈이라, 표시·광고 문제로
> 번질 수 있다.

---

## 2. 방향이 반대인 것

**국외 이전.** 생성기는 *"한국에 서버가 있으니 해외 이용자의 데이터가 한국으로 온다"* 고
썼다. 우리 사정은 그 반대다 — **한국 이용자의 데이터가 미국으로 나간다**(사진·영상은
Cloudflare, 알림은 Google). 한국 법상 별도 고지 항목이라 **가장 빠뜨리면 안 되는 부분**을
정확히 거꾸로 쓴 셈이다.

**아동 연령.** 생성기는 13세(미국)·16세(EU) 기준으로 썼다. **한국은 만 14세**다.

---

## 3. 빠진 것 (한국 법에서 요구하거나 필요한 것)

- **개인정보 보호책임자** 지정·공개 — 「개인정보 보호법」 제31조
- **파기 절차 및 방법**
- **권익침해 구제 방법** — 개인정보분쟁조정위원회 등 기관 안내
- **위탁**과 **제3자 제공**의 구분 — 우리 경우는 대부분 위탁이다
- **국외 이전 상세** — 이전받는 자·국가·항목·목적·시기·방법·보유기간, 그리고 거부 방법
- **카카오** — 우리의 가장 중요한 위탁처인데 생성기 결과물에 아예 없다
- 우리가 실제로 처리하는 항목들 — **사진·영상, 기기 알림 토큰, 밴드·일정·정산 기록,
  신고·차단 내역**
- **무료 밴드의 사진·영상이 30일 뒤 자동 삭제된다는 사실** — 이용자에게 가장 실질적인 내용인데
  생성기는 알 수 없다

---

## 4. 보관 기간이 우리와 다름

생성기: *"탈퇴 후 로그 90일 보관 → 그 후 30일 이내 삭제"*

실제: **탈퇴 후 90일 보관 후 파기**(`app.withdrawal.retention-days`). 로그를 90일 두는 게
아니라 회원 정보를 90일 두는 것이다. 그 밖에 알림 이력 30일, 무료 밴드 미디어 30일 등
생성기가 알 수 없는 기간이 여럿 있다.

---

## 5. 결론

생성기 결과물에서 **살릴 만한 것은 목차 구조 정도**였다. 내용은
[privacy-policy-ko.md](privacy-policy-ko.md) 로 새로 썼다.

다음에 다른 생성기를 쓴다면, **먼저 [privacy-facts.md](privacy-facts.md) 를 옆에 두고**
한 줄씩 대조할 것.
