## 4. 폐업할 때 — 이 순서로

순서가 중요하다. **결제를 먼저 막고 → 사용자에게 알리고 → 돈과 데이터를 정리하고 → 인프라를 끄고 → 마지막에 행정 신고.**
인프라를 먼저 끄면 결제 알림(RTDN)을 못 받아 환불·해지가 꼬이고, 방침에 적은 파기도 확인할 수 없다.

### 4-1. 새 결제 막기 (종료 결정 당일)

- [ ] **Play Console › 수익 창출 › 정기 결제** 에서 `premium_yearly`, `premium_yearly_2`~`_5` 각각의 기본 요금제 `yearly` 를
      **비활성화** → 새 구매가 막힌다. 이미 구독 중인 사람의 갱신은 비활성화만으로 멈추지 않는다(아래 4-3).
- [ ] 쿠폰을 발급하고 있었다면 발급 중단.

### 4-2. 사용자에게 알리기 (종료일 최소 30일 전 권장)

- [ ] 앱 공지·푸시·이메일로 종료일, 데이터 삭제일, 유료 구독 환불 방법을 알린다.
- [ ] **이용약관에는 서비스를 영구 종료할 때의 조항(공지 기간·환불)이 없다**(제8조는 일시 중단만 다룬다).
      종료가 가까워지면 약관을 먼저 고쳐 게시하거나, 공지에 기준을 분명히 적는다.
- [ ] 사용자가 자기 사진·영상을 내려받을 기간을 준다.

### 4-3. 유료 구독 정리

- [ ] 자동 갱신 중인 구독을 **해지**한다 — Play Console › 주문 관리에서 주문별로(구독자가 많으면 Play Developer API 로 일괄).
      해지하지 않으면 서비스가 없어도 Google 이 계속 청구한다.
- [ ] 남은 기간을 쓸 수 없게 되므로 **남은 기간만큼 환불**(부분 환불)을 검토한다. Play Console › 주문 관리 › 환불.
- [ ] 마지막 정산이 Google 결제 프로필 계좌로 들어올 때까지 결제 프로필과 계좌를 유지한다.

### 4-4. 앱 내리기

- [ ] **Play Console › 설정(고급 설정) › 앱 사용 가능 여부 › 게시 취소**(Unpublish). 이미 설치한 사람의 앱은 남아 있으니 서버를 끄기 전에 공지가 먼저다.
- [ ] Firebase App Distribution 테스터 그룹 정리.

### 4-5. 개인정보 파기 (방침 제4조 — 처리 목적이 끝나면 지체 없이)

- [ ] 운영 DB 전체 삭제(서버 인스턴스를 지우면 함께 사라진다 — 스냅샷·백업 옵션이 켜져 있으면 그것도 지운다).
- [ ] **R2 `bandule-prod` 버킷 전체 삭제** — 사진·영상뿐 아니라 **`db-backups/` 의 DB 덤프(회원정보 포함)** 가 들어 있다.
- [ ] Redis(세션) — 서버와 함께 사라진다.
- [ ] Firebase 프로젝트(`bandule-b94d2`, `bandapp-dev-67c6f`) 삭제 — 기기 푸시 토큰.
- [ ] 로컬 PC·노트북에 내려받은 덤프·`.env.prod` 사본이 있으면 지운다.
- [ ] 파기한 날짜와 범위를 기록해 둔다(문의 대응용).

### 4-6. 외부 서비스 끊기 (돈이 나가는 것부터)

- [ ] **Vultr 인스턴스 삭제**(Destroy) — 정지(Stop)는 과금이 계속된다. 스냅샷·예약 IP·자동 백업도 확인 후 삭제.
      계정에 남은 크레딧·결제 수단 정리.
- [ ] **Cloudflare R2** 버킷 삭제 후 R2 API 토큰 폐기. 결제 수단을 쓸 데가 없으면 R2 구독 해지.
- [ ] **Google Cloud** — Play Developer API 서비스 계정 키 폐기, Pub/Sub push 구독·토픽 삭제, 쓸 일이 없으면 프로젝트 종료(결제 계정 연결 해제).
- [ ] Play Console › 수익 창출 설정 › 실시간 개발자 알림 토픽 비우기.
- [ ] **카카오 개발자 앱** 삭제(또는 비활성화) — 앱 키 무효화.
- [ ] 메일 발송 — Resend 도메인·API 키 삭제.
- [ ] Cloudflare Email Routing 규칙, Pages 프로젝트(약관 사이트)는 **공지 기간 동안 유지**한 뒤 삭제.
- [ ] UptimeRobot 모니터 삭제.
- [ ] GitHub — Actions 시크릿(SSH 키·토큰) 삭제, 서버에 등록했던 배포용 SSH 키 폐기, 저장소는 보관(Archive).
- [ ] **도메인 `bandule.com`** — 자동 갱신 끄기. 공지·약관 페이지를 보여 줄 기간이 끝난 뒤 만료되게 둔다
      (바로 버리면 남이 사서 사칭할 수 있으니, 여유가 되면 한두 해 더 들고 있는 것도 방법).
- [ ] Google Play 개발자 계정 — 다른 앱에 쓸 거면 유지, 아니면 해지(등록비 $25 는 환불 없음).

### 4-7. 행정 신고 (마지막)

- [ ] **통신판매업 폐업신고** (정부24 또는 구청). **12월 31일 전에** 하면 다음 해 1월 등록면허세가 나오지 않는다.
- [ ] **사업자 폐업신고** (홈택스). 부가가치세 폐업 확정신고는 폐업일이 속한 달의 말일부터 25일 이내.
- [ ] 다음 해 5월 종합소득세 신고 때 밴듈 매출·경비 반영.

> 세무·법률 판단은 이 문서가 아니라 세무서·구청 안내가 기준이다. 신고 기한은 바뀔 수 있으니 폐업 시점에 다시 확인한다.
