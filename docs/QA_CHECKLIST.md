## 16. 다시 실행하는 명령

```powershell
.\gradlew.bat build --no-daemon --console=plain
python site/build.py
# Git Bash 안에서 실행 (WSL bash와 혼동하지 않는다)

cd client

flutter test
python tools/check_cache_invalidation.py
python tools/release_store.py --no-bump
```

기존 AAB만 확인하려면 client 폴더에서:

```powershell
python tools/release_store.py --check-only build/app/outputs/bundle/prodRelease/app-prod-release.aab
```

규칙 검사가 필수 도구 없이 성공하지 않는 회귀 검사는 CI `rules`에 넣었다. Git Bash에서도 실행 가능:

```bash
if PATH=/nonexistent /bin/sh tools/check-repo-rules.sh; then
  echo 'FAIL: 도구가 없는데 통과'; exit 1
fi
sh tools/check-repo-rules.sh
```
